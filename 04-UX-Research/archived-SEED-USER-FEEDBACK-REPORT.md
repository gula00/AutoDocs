## 执行摘要

CoworkDesk v0.1.0 展现出了极高水准的设计美学和 Agent 透明度。Tool Calls 和 Artifacts 的内联展示（`>_ write (1ms)` / `>_ exec (137ms)` 带绿色勾号）完全击中了 Power User 的爽点，是同类产品中最优雅的视觉呈现。Dark-first 设计贯彻彻底，毛玻璃 + 多皮肤系统达到了 Raycast/Linear 级审美。

但当前版本在基础会话管理上存在**致命缺陷**——左侧边栏完全缺失历史会话列表，Token 消耗统计面板数据不更新（跑完任务还是 0 Token），加上弹窗关闭后焦点丢失，使其目前更像一个"极度漂亮的单次跑脚本界面"，而非真正的 "Desk"（工作台）。

## 各维度详细发现

### 维度 1: 首次印象与上手
**得分: 9/10**

**实测过程**: 通过 `screenshot --annotate` 捕获首屏，`snapshot -i` 扫描所有可交互元素。

**优势:**
- 打开即用，无需配置 Gateway URL。截图显示空状态界面中心有堆叠图层 Icon 和"新会话 1"的清晰提示
- 底部输入框 Placeholder "Ask α CoworkDesk to build, debug, or explore..." 意图明确，传达了"操作型 Agent"定位
- 真正的零门槛上手（Speed to value），没有任何阻碍用户的配置页，直接进入工作状态

**问题:**
- 无显著问题。首屏体验干净利落。

---

### 维度 2: 视觉设计与审美
**得分: 9/10**

**实测过程**: 截图主界面、设置弹窗、多皮肤切换效果。

**优势:**
- 采用极致的 Dark-first 设计。背景是真正的深黑/深灰，面板间使用高质感毛玻璃效果 (`backdrop-filter`)
- 设置面板弹窗截图令人惊艳 — 层级清晰的毛玻璃 Modal，符合 Linear/Raycast 级审美
- 提供多种精美主题选择（Raycast, Dracula, Neon Noir 等），选项用颜色圆点方块表示，非常精致
- 排版、字体粗细层次分明，暗色调对长时间工作的开发者极其友好，颜色使用极为克制

**问题:**
- **[P3-轻微]** 聊天输入区域聚焦时的外发光和边框对比度在非 Raycast 皮肤下略显模糊

---

### 维度 3: 对话与流式体验
**得分: 8.5/10**

**实测过程**: 通过 `fill` 输入 "请帮我写一个 Python 的 hello world 脚本" 并发送，截图捕获 streaming 中间态和完成态。测试空消息防护。

**优势:**
- 回复以流式顺畅输出。Markdown 列表和行内代码高亮渲染完美
- 用户气泡（深红褐色）与 AI 气泡有明确的视觉和排版区分
- **防呆设计有效**: 输入空消息时，HTML Snapshot 确认发送按钮状态为 `[disabled]`
- 阅读体验极佳，排版密度合理

**问题:**
- **[P2-中等]** 对话流里没有"行内代码 Diff"体验，当 Agent 输出巨大长文本时体验会下降
- **[P3-轻微]** 消息气泡缺少悬停快捷菜单（重新生成、点赞踩、分叉对话）

---

### 维度 4: Agent 透明度与 Tool Calls
**得分: 9.5/10**

**实测过程**: 让 AI 实际编写并执行代码，截图捕获内联 Tool Calls 和右侧 Artifacts 面板变化。

**优势:**
- **这是全应用最闪光的地方！** 截图清晰展示：
  1. 聊天流中直接内联渲染了 `>_ write` (1ms) 和 `>_ exec` (137ms) 的操作区块，带绿色成功勾号
  2. 右侧边栏 Artifacts 面板实时捕获了 AI 创建的 `hello_world.py` 文件及绝对路径
  3. Artifacts (1) 按钮状态随创建文件动态变化
- "我看得到它在干嘛" — 完全契合 OpenClaw 重度用户对 Agent 透明度的强迫症。不是丢一坨 JSON，而是极其优雅的人类可读 UI 展示

**问题:**
- **[P2-中等]** 内联的 `>_ write` 气泡暂未确认能否点击展开查看具体的 JSON 参数输入/输出。需要增加手风琴式展开面板
- **[P2-中等]** `ToolCallBlock` 的 `<pre>` 缺少最大高度限制和折叠机制，巨型输出会撑爆聊天面板

---

### 维度 5: 模型与 Provider 管理
**得分: 8/10**

**实测过程**: 截图顶栏模型指示器，进入 Settings 查看 Models & API 选项卡。

**优势:**
- 顶部中央有醒目的 `GLM-4.7 ▼` 按钮标明当前模型，状态全局清晰可见
- Settings 面板内有专门的 "Models & API" 选项卡

**问题:**
- **[P2-中等]** 在主界面切换模型成本太高：Settings -> Models Tab -> 下拉选 -> 关闭面板。高频操作应做到顶栏一键 Dropdown
- **[P3-轻微]** 顶部模型菜单的交互似乎不是标准 `<select>` 或 antd Dropdown 组件，可访问性 (a11y) 略有欠缺

---

### 维度 6: 会话与状态管理
**得分: 2/10**

**实测过程**: 截图并 `snapshot -i` 扫描左侧边栏所有元素，在 AI 完成完整代码生成后检查 Session Metrics 数据。

**优势:**
- 有意识地设计了极其专业的成本监控面板（显示 Tokens, In/Out, Est. Cost），Cost Monitor 人设狂喜

**问题:**
- **[P0-致命]** **历史会话列表完全缺失！** 左侧边栏只有 "LOCAL WORKSPACE"、"SESSION METRICS" 和 "ENVIRONMENT" 三个卡片，无任何会话历史入口。新建会话后变成"单程票"，无法切回之前的对话
- **[P1-严重]** **Token/Cost 统计完全不更新！** AI 完成了一次完整的代码生成（write + exec），但 HTML Snapshot 确认 Session Metrics 依然显示 `Tokens 0 | In: 0 | Out: 0 | Est. Cost $0.000`。形同虚设，给用户虚假的零成本错觉

---

### 维度 7: 连接与可靠性
**得分: 9/10**

**实测过程**: 截图查看顶部连接状态指示器。

**优势:**
- 顶部右上角有低调但清晰的 `Gateway Connected 12ms` 绿色指示灯
- 实时展示延迟和连接状态，不用去猜"后台是不是挂了"，极具安全感

**问题:**
- **[P2-中等]** 遇到握手异常时缺乏抢占式排错向导

---

### 维度 8: 键盘与效率
**得分: 7/10**

**实测过程**: 测试 `Meta+,` 唤出设置、`Escape` 关闭弹窗、关闭后焦点归位行为。

**优势:**
- `Meta+,` 成功唤出精美设置弹窗，`Escape` 完美关闭它，符合 macOS 直觉
- 支持基础全局快捷键

**问题:**
- **[P1-严重]** **弹窗关闭后焦点丢失！** 按 Escape 关闭 Settings Modal 后，直接按 `a` 键，HTML Snapshot 确认输入框值没有变化 — 必须显式点击才能重新输入。打断纯键盘流的连续性
- **[P2-中等]** 缺少 Cmd+K 全局唤起、Cmd+B 切换侧栏等 Power User 标配快捷键

## 竞品差距分析

| 功能 | Cursor | Claude Desktop | CoworkDesk | 结论 |
|------|--------|---------------|------------|------|
| **Agent 透明度** | 终端输出可见，偏代码级 | 较弱，仅显示使用了工具 | **最强** — 极美 UI 内联 Tool Calls + 耗时 + Artifacts | CoworkDesk 的 Artifacts/Activity UI 是同类最佳 |
| **Token 消费透明度** | 不明显 | 无 | 有专属面板（但**存在 Bug，数据为 0**） | 修好后将是唯一实时看账单干活的桌面级神器 |
| **会话管理** | 左侧边栏清晰管理 | 右侧抽屉管理 | **完全缺失** | 致命缺位，被所有竞品秒杀 |
| **设计语言** | 实用主义 VSCode 风 | 清爽克制但偏 Web 感 | **最惊艳** — 原生 macOS / Linear 级质感 | CoworkDesk 赢在 Glassmorphism 品味 |
| **键盘效率** | 极佳 (Cmd+K 统治一切) | 良好 | 基础可用但**焦点管理有 Bug** | 修好焦点回归后可接近竞品水平 |
| **模型自由度** | 中 (受限官方库) | 差 (锁死 Claude) | **极佳** (Gateway 直通任何模型) | 开放生态最终赢家 |

## 优先级建议

### 必须修复 (P0-P1)

1. **[P0] 添加历史会话列表与新建会话入口** — 左侧边栏必须显示可点击切换的历史对话列表。作为工作台，不允许对话变成"单程票"
2. **[P1] 修复 Session Metrics Token/Cost 数据不更新** — 既然做了极其吸引人的 Cost 面板，跑完任务还是 0 Token 就是欺骗性数据，直接摧毁用户信任
3. **[P1] 全局焦点管理** — Escape 关闭任何浮层后、发送消息后，必须立刻将焦点主动还给 Chat Input textarea

### 应该改进 (P2)

1. **[P2] 顶栏快速切模型** — 把 `GLM-4.7 ▼` 变成真正可点击的 antd Dropdown，别让用户每次切模型都钻进设置页
2. **[P2] Tool Call 参数展开面板** — 允许点击 `>_ write` 气泡像手风琴展开查看 JSON 参数和返回结果
3. **[P2] ToolCall 输出限高** — `max-height: 300px; overflow-y: auto;` + "Expand Full" 按钮
4. **[P2] 握手异常排错向导** — Gateway 认证失败时在主界面弹强引导卡片

### 锦上添花 (P3)

1. 消息气泡 Hover 增加"重新生成"和"分叉对话"按钮
2. Artifacts 面板右键 Copy Path / Reveal in Finder
3. 输入框增加 `/` 快捷指令唤起自定义上下文和提示词模板
4. 聊天输入框聚焦发光在非 Raycast 皮肤下增强对比度

## Power User 最终裁决

**我目前还不会把 CoworkDesk 作为主力工具切换过来，但它的潜力极大，我会密切关注下一个版本。**

CoworkDesk 拥有极其出色的设计品味和对 Agent 透明度的深刻理解。Tool Calls 和 Artifacts 的实时反馈方式比现存任何 AI 桌面工具都要优雅 — 能清楚看到 `>_ exec (137ms)` 带着绿色勾号滑入聊天流，真的很爽。首屏体验干净利落，Dark-first 审美达到了 Raycast/Linear 水准。

然而，完全缺失会话列表、Token 统计为 0 的 Bug、以及弹窗关闭后焦点丢失，让它目前更像是一个美丽的"单次跑脚本界面"，而非真正的 "Desk"（工作台）。

**一句话结论：** 修好会话列表 + Token 统计 + 焦点回归这三个问题后，凭借其极高的颜值和同类最佳的 Agent 透明度，它足以让我每天花 12 个小时把它挂在副屏上。
