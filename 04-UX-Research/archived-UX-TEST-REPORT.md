## 致命问题（必须修复）

### 1. ~~代码块渲染出现 `[object Object]`~~ ✅ 已修复

- **修复验收**: 代码块在 streaming 中正确渲染文本，不再出现 `[object Object]`
- **人设视角**: 以"开发者用户"身份发现
- **场景还原**: 向 AI 提问"帮我写一个 hello world 的 Python 脚本" → AI 回复包含代码块 → 代码块中出现 `[object Object],(,[object Object],)` 和 `[object Object], +x hello.py`
- **用户感受**: "代码都渲染坏了，这怎么复制？点 Copy 复制出来的是对的吗？太不靠谱了，我怎么敢用它写代码。"
- **建议**: 检查 `CodeBlock` 或 `MessageItem` 组件中对 streaming delta 的拼接逻辑。大概率是在合并 streaming text 时，将某个对象（而非字符串）直接拼接到了输出中。重点排查 `chatStore.handleAgentStream` 中 `mergeStreamText` 的处理
- **参考**: Cursor / Claude Desktop 的代码块在 streaming 中也是逐字渲染的，从未出现此类问题

### 2. ~~右侧面板完全是空白占位符~~ ✅ 已修复

- **修复验收**: 右侧面板不再以空白 placeholder 占据屏幕空间，布局合理
- **人设视角**: 以"AI 新手"身份发现
- **场景还原**: 首次打开应用 → 看到三栏布局 → 右侧上半部分写着"Agent 修改文件后将在此预览"，下半部分写着"Agent 执行命令后将在此显示输出" → 但这两个区域永远是空的
- **用户感受**: "右边这一大片空白是什么？是我的应用没加载好吗？这占了屏幕快 1/3 的空间，啥也不显示。"
- **建议**: 要么把右侧面板隐藏/折叠（stub 功能不该占空间），要么放一个更有意义的空状态引导（比如"开始对话后，AI 修改的文件将在这里预览"配一个示意图）。当前的纯文字 placeholder 对用户来说就是"坏了"
- **参考**: Cursor 的右侧面板只在有 diff 时才展开；Claude Desktop 根本没有侧面板

### 3. ~~Agent 工具调用过程完全不可见~~ ✅ 已修复

- **修复验收**: 工具调用过程已可视化，用户能看到 Agent 的操作步骤
- **人设视角**: 效率狂魔（Cursor 用户）+ 产品经理
- **场景还原**: 向 Agent 下达一个需要多步操作的任务（如"帮我看一下项目结构并修改某个文件"）→ Agent 在后台执行了多个工具调用（ls、bash、read_file、write_file 等）→ UI 中完全没有展示这些工具调用的过程，用户只能看到最终的文字回复
- **用户感受**: "它到底做了什么？是真的改了我的文件还是只在说？我看不到它执行了哪些命令、读了哪些文件、改了什么内容。在 Cursor 里，每一步 Terminal 执行、文件读取、文件写入都有可展开的区块，能看到完整的输入输出。这里就像在跟一个'黑箱'对话。"
- **严重程度**: 对于一个 AI Agent 桌面产品来说，这是**产品定位级的缺失**。Agent 的核心价值是"替用户执行操作"，如果执行过程不透明，用户无法信任 Agent、无法纠错、无法学习。这不是 UI bug，而是核心产品能力的缺失
- **建议**:
  1. 每个工具调用应显示为可折叠/展开的区块（参考 Cursor 的 Terminal/Read/Write 块）
  2. 区块应包含：工具名称、输入参数摘要、执行状态（进行中/成功/失败）、输出结果（可折叠）
  3. 代码修改类工具应展示 diff 视图（这也与右侧文件预览面板的设计意图吻合）
  4. 检查 `ToolCallBlock.tsx` 组件是否已有渲染逻辑但未被正确触发，以及 `chatStore` 中 streaming handler 是否正确解析并存储了工具调用事件
- **参考**: Cursor 的每一步操作（终端命令、文件读取、文件写入、搜索）都有独立可视化区块；Claude Desktop 的工具调用以折叠卡片形式展示；ChatGPT Desktop 的 Code Interpreter 会实时显示代码执行过程

## 体验摩擦点（应该修复）

### 1. ~~没有任何快捷键~~ ✅ 已修复

- **修复验收**: 快捷键已支持
- **人设视角**: 效率狂魔（Cursor 用户）
- **用户感受**: "我习惯 Cmd+K 打开对话、Cmd+N 新会话、Cmd+/ 切侧边栏，这里一个快捷键都没有。全靠鼠标点，太慢了。"
- **建议**: 至少支持 Cmd+N（新会话）、Esc（停止生成）、Cmd+,（设置）

### 2. ~~Gateway 连接配置门槛高~~ ✅ 已修复

- **修复验收**: Gateway 配置体验已改善
- **人设视角**: AI 新手
- **用户感受**: "打开设置，看到 Gateway 地址 `ws://127.0.0.1:18789`、认证 Token、认证密码……我完全不知道这是什么。为什么用一个 AI 助手还需要配置 WebSocket 地址？"
- **建议**: 首次使用时应有一个简化的引导流程；Gateway 连接细节应该尽量隐藏到"高级设置"里

### 3. ~~模型都显示"未设置" API Key~~ ✅ 已修复

- **修复验收**: 模型状态展示已优化
- **人设视角**: 产品经理
- **用户感受**: "列了 6 个模型，全都显示'未设置'。那到底在用哪个模型？为什么能正常对话？这个列表的存在意义是什么？"
- **建议**: 如果是通过 Gateway 统一管理模型密钥，应该明确告知用户"模型由 Gateway 管理，无需在此设置 API Key"；当前的展示方式让人以为配置不完整

### 4. ~~"推送模型配置到 Gateway" 概念不清~~ ✅ 已修复

- **修复验收**: 按钮文案已改为更直觉的说法
- **人设视角**: 产品经理
- **用户感受**: "推送？Gateway？这是在说什么？我只是想换个模型聊天而已。"
- **建议**: 按钮文案改为更直觉的说法，如"应用模型设置"；或者在对话界面直接提供模型切换下拉框

### 5. ~~会话侧边栏只有一个"主对话"~~ ✅ 已修复

- **修复验收**: 会话管理体验已改善
- **人设视角**: 效率狂魔
- **用户感受**: "就一个主对话，怎么多开？虽然有个 + 按钮，但点了没看到明显反馈。不能像 ChatGPT 那样随意开新对话、给对话命名、搜索历史。"
- **建议**: 新建会话后应立即切到新会话并聚焦输入框；会话应支持重命名

### 6. ~~用户头像显示"你"不够友好~~ ✅ 已修复

- **修复验收**: 用户标签显示已改善
- **人设视角**: 视觉洁癖
- **用户感受**: "消息头部写着'你 01:31'，这个'你'字很奇怪。我是'我'啊，不是'你'。应该显示我的名字或者至少显示'我'。"
- **建议**: 改为"我"或直接用用户名；或者干脆不显示用户名，只用头像区分

### 7. ~~发送按钮 disabled 时视觉反馈不够~~ ✅ 已修复

- **修复验收**: 发送按钮的禁用/可用状态视觉区分已增强
- **人设视角**: AI 新手
- **用户感受**: "输入框是空的，发送按钮是灰色的。但灰色和可用状态的差别太小了，我以为 gateway 断了。"
- **建议**: 空输入时隐藏发送按钮或让它完全置灰；有输入后按钮变亮的变化应该更明显

## 微优化建议（锦上添花）

### 1. Streaming 时显示 token 计数或耗时

- **具体方案**: 在 AI 回复底部实时显示已生成 token 数和耗时，回复完成后固化
- **预期效果**: 减少"它还在回复吗？要多久？"的焦虑感

### 2. 代码块增加语言标签高亮

- **具体方案**: 代码块头部现在只显示 `bash`，可以用更显眼的 tag 样式，并且给 Python/JS/TS 等用不同的 accent color
- **预期效果**: 快速识别代码类型，提升专业感

### 3. 暗色模式下输入框边框应更明显

- **具体方案**: 暗色模式下输入框的边框和背景对比度较低，聚焦时高亮效果不够
- **预期效果**: 更容易定位输入焦点

### 4. 消息气泡增加 hover 操作

- **具体方案**: 鼠标悬停消息时显示"复制""重新生成"等操作按钮
- **预期效果**: 参考 ChatGPT Desktop 的消息 hover 操作栏

## 做得好的地方

- **"正在思考"动画**: 红色三点 loading 动画很醒目，让用户知道 AI 在工作，不是卡了
- **暗色主题完整度**: Light/Dark 切换全局生效，没有遗漏的组件，颜色协调
- **对话基本流畅**: Streaming 输出顺畅，消息列表自动滚动跟随，发送→回复的核心链路是通的
- **Gateway 连接状态指示**: 右上角绿色圆点 + "已连接"标签，简洁有效
- **输入框 placeholder "描述你想完成的任务..."**: 比"输入消息"更有引导感，暗示这是一个任务执行工具
- **代码块 Copy 按钮**: 位置合理，一键复制
